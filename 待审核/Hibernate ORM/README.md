各篇共用商品 `ProductEntity` 的示例，字段和表结构按项目定义。示例沿用 Jakarta Persistence（JPA）接口，必要处标出 Hibernate 或 Spring Boot 专属设置。实际接入时按项目选定的版本查阅对应官方文档。

映射采用 **Java 注解**。在实体上写清表名、主键、列名和适用的约束、索引及注释，业务映射通过实体扫描或程序化注册生效。数据库迁移脚本管理实际表结构，修改表结构时一起核对脚本和注解。[实体映射示例](<02 实体映射与数据库结构.md>)

关联优先保留 ID。一般不做级联查询，由 **DAO 或 Service 显式查询**所需数据并组装结果。确需级联查询时，须先取得人工明确确认。查询不做懒加载。[查询与加载](<03 查询与加载.md#3-选择加载方式并排查-n1>) · [级联查询的确认要求](<03 查询与加载.md#31-级联查询须经人工确认>)

关联数据由 **Service 显式写入**，不做级联。Service 明确处理新增、修改、删除以及相关操作的事务边界。[事务与更新](<04 事务与更新.md#11-service-显式处理关联写入>)

评审时分别确认接入方式、实体与结构管理、查询与加载、事务与更新四部分的建议。每篇的适用条件和验证方法可独立讨论。
