# 项目说明候选

> 状态：待审核参考材料。这是一份可选说明提纲，不描述本仓库的业务，也不要求使用方按此建立文档。
>
> 适用范围：需要帮助开发者快速了解目标、边界和依据的软件项目；内容由具体项目自行维护。

## 可按需填写的内容

| 内容 | 需要说清楚什么 |
| --- | --- |
| 项目目标 | 解决什么问题，当前交付目标是什么 |
| 使用对象 | 实际有哪些使用者，各自关注什么；不预设角色或端的数量 |
| 本期范围 | 已确认要做什么，哪些仍待确认或明确暂缓 |
| 关键业务依据 | 已确认规则在哪里，涉及哪些重要关系、状态或计算逻辑 |
| 技术与环境 | 实际使用的技术、模块和运行环境；区分已核实信息与计划 |
| 阅读入口 | 需求、接口、数据和运行说明的有效入口，避免重复抄写正文 |
| 当前进度 | 已完成、未验证和未解决事项，以及核对时点 |

## 使用这类说明时的注意点

- 只保留有助于理解项目的信息，不把所有代码、字段和操作步骤搬进概况。
- 规则、现状和计划分别写清楚。现有代码能证明当前实现，不一定证明业务决定正确；草案也不自动成为已确认需求。
- 发现文档、代码与明确需求冲突时，列明差异和来源，再判断影响；不凭名称猜测业务规则。
- 具体业务数据、角色划分、模块命名和例外由项目说明，本规范库不替使用方定义或维护。
- 这份说明不提供额外操作权限，也不自动恢复已暂停的任务。

## 仍需评审

是否有必要把上述提纲作为通用参考模板；如收录，应保持可选和简短，避免让简单项目维护重复文档。
