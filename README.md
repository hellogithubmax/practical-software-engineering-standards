# 实用软件工程规范

Practical Software Engineering Standards

面向实际开发的软件工程规范，强调实用、稳定、易读和好维护。用直白的话说明做法和理由，优先成熟方案，增加复杂度需要有实际收益。

本规范独立维护，使用方自主决定是否采用、怎样引用和如何落地。具体边界见[仓库维护约定](AGENTS.md#repository-scope)。

| 文档 | 适用范围与内容 |

| [Java 通用代码规范](<Java 通用代码规范.md>) | Java类型、命名、注释和编码 |
| [ORM 编码规范](<ORM 编码规范.md>) | 采用MyBatis-Plus的数据访问与映射 |
| [数据库设计规范](数据库设计规范.md) | Java／MySQL场景中的数据库设计 |
| [AI 辅助开发规范](<AI 辅助开发规范.md>) | AI辅助开发的执行与交付 |

专题按各自适用范围使用，不要求所有项目采用同一套技术。

## 维护入口

- [待审核](待审核/AGENTS.md)：新增、尚未审完的候选和参考材料。
- [待后续处理](待后续处理/AGENTS.md)：已发现但尚未解决的遗留问题。

候选内容只有明确通过审核后才纳入正文；本仓库不维护具体项目的业务源码、运行数据或个人环境配置。
