# 实用软件工程规范

Practical Software Engineering Standards

面向实际开发的软件工程规范，强调实用、稳定、易读和好维护。本规范独立维护，由各项目按自身需要采用。

## 先看基础，再选专题

- [首次接入或引用条款](<00-00 规范总览.md#6-其他项目怎样引用>)，了解本地登记、选用条款和固定版本的写法。
- [按任务查条款](<00-00 规范总览.md#4-按问题定位正文>)，由具体工作直达正文。
- [按专题查适用范围](<00-00 规范总览.md#各文档的适用范围>)，从通用基础选到需要配套的专题。
- [查技术参考资料](<00-00 规范总览.md#7-技术参考资料入口>)，定位规范引用的官方文档和技术依据。
- [查规则确认状态](<00-00 规范总览.md#5-规范正文与维护材料>)，查阅已确认、待审核和暂存事项。
